Read the example record LEVELS L0 B482 L1 B613 L2 B1210  S L2 D3  S L0 D1  S L2 D3  S L1 D7  SEEN D2  END as follows. The emitter has three PRI levels, named L0–L2 in ascending order and quantised to bins (B482 ≈ 119.6 µs). It cycles through four states, listed backwards in time from the end of the window: the state in progress when the window ends is L2 for 3 pulses, the one before it was L0 for 1 pulse, and so on. Two of the states — L2 for 3 pulses — are identical and become one state in the emitter model, visited twice per cycle. SEEN D2 says that 2 of the current state's 3 pulses have been observed, so the emitter will stay one more pulse before moving on. In terms of the emitter model, the LEVELS block gives the components Φ, each S block gives a state in θ, the order of the S blocks gives the state sequence λ, and SEEN gives the phase.
